# Express.js + TypeScript Starter

This project is a lightweight Express.js backend written in **TypeScript**, built for scalability and modern development workflows.  
It uses **Vite-style fast reloading** via `ts-node-dev` or `nodemon`, and package management via **Yarn**.

---

## 🚀 Features

- ⚡ Built with **Express.js**
- 🔒 Written in **TypeScript**
- 🧠 Includes basic project structure
- 🔁 Hot reload for development
- 🧩 Environment variable support (`.env`)
- ✅ ESLint + Prettier ready (optional)

---

## 🛠️ Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or newer)
- [Yarn](https://yarnpkg.com/) (v1.22+)
  

Install Dependencies and start command

- yarn install
- yarn dev
